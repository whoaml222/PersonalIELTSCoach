# 先回忆再揭示中文，整句连续朗读

## 记忆卡

- 新概念第一、二册的“英文选中文”、四级词汇、单词复习使用同一种记忆流程。最初只展示英文、音标和已有英文例句，不把中文选项或例句翻译放进界面及无障碍文本。
- “先回忆 2–3 秒”是提示，不是强制倒计时。想起后点“想起来了，核对意思”并如实自评；想不起来再点“想不起来，看中文选项”。
- 看过中文选项，或在回忆阶段主动点词查释义，都会记为借助提示。提示后选对仍计入当天学习量，不增加错词次数，但不累加独立回忆次数；明天再测。真正答错仍按原规则加入错词记录。
- 保存成功后，先点“遮住中文，再回忆一次”，再进入下一个词。再次查看答案不会额外累计学习量或掌握次数。
- 换词、状态恢复与保存失败均有保护；上一词的展开状态不会被套到新词，保存中不能重复作答，失败时可以重试。
- “中文输入英文”和例句填空仍保留用于作答的中文题干；主动打开的词典释义、错词本参考内容及界面文字不统一遮掉。
- 错词本是显示释义的参考页，“已看懂，明天再测”也按提示学习处理，不能绕过独立回忆规则直接增加掌握次数。
- 不删除旧记录，不变更数据库结构，原有每日目标、继续加学和四级/新概念复习配额保持不变。

## 朗读

- 原版固定每 3 词拆一段，失败时继续拆短。这次取消这种流程，不再用单词录音拼出句子。
- 单词继续使用有道英音，已有单词缓存继续可用。句子和短语采用百度翻译英音参数，一次提交完整英文、一次播放完整音频，保留逗号、句号、缩写和连字符。
- 新的句子缓存与旧分段缓存隔离。网络/服务失败时提示重试，不偷偷改成系统声音或逐词拼读；仍保留停止、取消、有限重试和音频大小限制。
- 单次文本上限保持 500 字符。自带原录音的个人阅读课程继续离线播放原音频。
- 只有点击发音才向相应服务发送当前英文，服务方也会收到网络 IP。不上传整本课程、学习记录或密钥。缓存可能被系统清理；不要朗读密码或身份号码等敏感内容。
- 朗读不调用 OpenAI，不使用付费 API 密钥，不新增 GPT Token 费用。在线网站接口并非可承诺永久可用的付费 SLA；音色和网络情况仍需在手机上试听确认。
