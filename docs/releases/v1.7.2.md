# v1.7.2 — 新概念第二册与连续学习

## 第二册词汇

- 按用户指定词表加入新概念英语第二册 96 课、877 条词条，同册重复词合并为 851 张学习卡，保留全部对应课号和义项。
- 每张卡包含简短中英例句、音标或待核对提示，以及离线点词释义和语法提示。例句为本 APP 编写或沿用已有原创内容，不打包网站课文或音频。
- 校正部分词性、中文释义及同形异音词音标；学习卡的目标词弹窗优先显示当前册的释义和音标，避免被另一册的同拼写词覆盖。

## 学习衔接与复习

- 第一册的新词全部接触后，自动紧接第二册；不必等到第一册全部达到“已掌握”。同一批可以从第一册剩余词接到第二册。
- 每日目标仍为 20 个，学完可主动选择继续学习 20 个。
- 复习保留 Paul1000 与新概念各半的规则，第一册和第二册合并占新概念的一半配额，按到期时间安排；一边不足时由另一边补足。
- 保留第一册、Paul1000 的学习进度、错词和复习时间；跨册同拼写词可能有不同义项，因此分别保留学习卡。
- 学习页面显示所属册数和进度，修正较长课号挤压发音按钮的布局。

## 更新与隐私

请覆盖升级，不要卸载旧版。词库、例句和语法提示可离线使用；未缓存的词典发音仍需联网，播放后沿用原缓存机制。本次不更换语音服务、不增加权限或后台上传，也不新增 GPT Token 费用。私人阅读课程不包含在公开 APK 或源码中，无需因本次更新重新导入。
