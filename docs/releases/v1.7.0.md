# v1.7.0 — 阅读书架与学习质量更新

## 新增与改进

- 新增本地阅读课程书架：导入 `.ieltscourse` 数据包、逐句/全文阅读、断点续读、原录音播放、变速和独立阅读生词本。公开安装包不附带第三方私人课文或录音。
- NCE1 / Paul1000 的单词例句改为逐词明确编写的用法，修正不自然搭配和部分词义、词性错误。
- 学习、复习和阅读页面统一支持点词：中文参考释义、单词独立英音、原形及离线句法提示；扩大常用发音按钮的点击区域。
- 保留每日 NCE1 20 词、Paul1000 30 词的首轮目标，完成后可继续学习；两类到期词按现有规则平衡复习。

## 修复与安全

- 修复学习重复计数、旧异步结果覆盖新会话、阅读位置恢复和自由阅读页面重建后的状态丢失。
- 改进音频取消、切页、焦点和耳机断开处理；过长文字明确提示，不静默截断。
- 加固课程包路径、文件类型、大小、JSON 深度及引用校验；大型课程正文保存在私有文件，避免数据库单行读取限制。
- 加固更新签名验证、网络响应大小、加密凭据故障处理及备份排除规则。密钥存储不可用时仍能离线学习，不回退到明文密钥。
- 保留既有学习数据；请按原签名覆盖升级，不要先卸载。卸载会删除本机学习记录和导入的课程。

## 验证与边界

发布前本地全量测试 76 项通过，页面测试单独复跑通过。升级迁移覆盖 Android API 26、28、34 的模拟运行环境。公开 CI 不包含私人课程文件，因此私人资料导入的可选测试会跳过，其余测试仍执行。

本地阅读、释义和内置句法提示不调用 GPT。未缓存的词典发音会向在线词典发送点播文字；可选 AI 分析和写作批改仍需用户配置 API。离线释义和句法提示可能有误，原录音不保证标准英音，也不宣称已与逐句文本精准对齐。

真机音质、厂商系统兼容性和长时间使用体验尚待实机验证。静态检查保留旧目标 SDK 警告和少量性能建议，不承诺完全没有 BUG。
