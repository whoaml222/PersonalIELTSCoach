# v1.7.4 — 先回忆再看中文，整句连续英音

## 记忆卡

- 新概念第一、二册的“英文选中文”、四级词汇和单词复习默认遮住中文选项与例句翻译。先看英文回忆 2–3 秒，想不起来再主动展开中文；这不是强制倒计时。
- 想起后可核对意思并自评。看过选项或在回忆阶段点词查释义后认对，仍记入当天学习量，但不累计独立掌握次数、不增加错词次数，安排明天再测。
- 答完先“遮住中文，再回忆一次”，再进入下一个单词。重新核对不会重复增加学习量或掌握次数。
- 修正重启后旧词的展开状态可能被带到新词的问题；保存中不能重复作答，保存失败可重试。错词本里的“已看懂，明天再测”也不会绕过独立回忆规则。
- “中文输入英文”和例句填空保留作答所需的中文题干；主动查词弹窗与错词本仍可查看释义。新概念每天 20 个、四级每天 30 个及继续加学、各半复习规则保持不变，不清空旧记录。

## 整句与短语朗读

- 取消原先每 3 个词分段、失败后再拆短的播放方式。句子和短语用百度翻译英音参数整段请求、整段播放，保留自然标点；不再用词语录音拼接成句子。
- 单词继续使用有道英音，旧单词缓存保留；新整句缓存与旧分段缓存隔离，首次播放需联网，缓存后可离线重听。个人阅读课程的原录音不受影响。
- 网络或语音服务失败时提示重试，不退回系统声音或逐词拼读。单次仍限 500 字符；停止、取消和有限重试保持可用。在线服务可用性及实际手机音效仍受网络与服务方影响。

## 隐私、费用与更新

只有点击朗读时，当前英文才会发送到语音服务：单词到有道词典，句子/短语到百度翻译。服务方也会收到网络 IP；不要朗读密码或身份号码等敏感信息。不上传整本课程、学习记录或密钥，不调用 GPT 朗读，也不新增 GPT Token 费用。缓存可能被系统清理。本次不增加权限，不打包私人课程或临时试听文件。

在“设置 → 应用更新 → 立即检查更新”下载正式安装包，**覆盖安装，不要卸载旧版**。Android 仍需要用户确认安装。
