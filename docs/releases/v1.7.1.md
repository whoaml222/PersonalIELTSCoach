# v1.7.1 — 整句语法讲解与逐句中文

## 学习界面

- 移除独立的“句子精读”和“写作练习”模块，以及每日写作要求；今日计划调整为四项。保留 Paul1000 单词、阅读器内的逐句精读和已有学习记录。
- 升级时恢复到旧模块页面会自动返回首页，不再打开已移除的功能。
- 点词弹窗先显示基础释义和发音入口，再补充离线资料，减少首次打开时的空白等待。

## 看句子学语法

- 新增整句时态、主语/谓语/宾语或表语、分句类型、动词组构成、词形变化和对比例句。
- 按完整动词组区分过去进行时、完成时、被动语态等，不再只凭 was、have 或 -ing 判断；区分时间短语、状语从句及介词后的 -ing 形式。
- 新语法说明在本机运行，不产生 GPT Token 费用。未覆盖或缺少标注的句子明确提示；离线提示不能保证所有复杂句都分析正确。

## 阅读器与兼容

- 逐句精读的中文参考只显示当前句子的译文。翻页后重新隐藏中文，不再用整篇译文代替本句译文。
- 旧课程缺少逐句译文时会提示补充；请重新导入配套的新版个人课程包。仅更新 APP 不会自动改写私人课程正文。
- 同一课程更新后按稳定句子编号保留阅读位置、原音频位置、完成状态和收藏；支持重新导入合法课程包恢复损坏的旧课程文件。
- 修正带句点缩写的语法标注边界，保留课程包路径、文件类型、大小及结构校验。
