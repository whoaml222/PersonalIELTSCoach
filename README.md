# Personal IELTS Coach

Personal IELTS Coach 是一款 Android 雅思学习辅助应用。

## 下载

请前往本仓库的 [Releases](https://github.com/whoaml222/PersonalIELTSCoach/releases) 页面下载安装包。

## 安装与更新

- 支持 Android 8.0 及以上版本。
- 首次安装时，Android 可能要求允许浏览器或文件管理器安装未知来源应用。
- 应用内支持检查新版本；检测到更新后会提示下载并由 Android 系统确认安装。

## 隐私说明

本仓库仅用于发布安装包和版本更新，不包含应用源代码、签名密钥、API 密钥或用户数据。
