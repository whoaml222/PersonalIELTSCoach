# 四级词汇离线词包

来源：[用户指定的四级词表](https://www.ncego.com/words/topic/cet4)，核对日期 2026-11-02，共 **4,458 个不重复词条**。这只是该网站的词表范围，不宣称是考试机构的唯一官方清单。

## 内容与限制

- `vocabulary.json` 保存网页公开数据中的词目、音标、简短释义和来源 ID。HTML 快照仅在本地忽略目录 `tmp/cet4/`，不会成为 APP 的网络依赖。
- 原页面按随机顺序显示；生成器按稳定的来源 ID 排列，避免每次刷新词表后重新排序。升级迁移的旧词保留原数据库 ID，后续新增词按来源顺序加入。
- 网页没有配套例句。APP 只沿用自身已有的简短中英例句，并要求目标词确实出现在句中、长度不超过 18 个空格分隔词。沿用例句时一并保留对应释义和音标，不将不同义项强行拼接。
- 尚无合适例句的词仍可学习、发音、记录掌握情况和复习；页面明确提示“此词暂未配例句”。不使用“请记住这个词”等模板填充，也不自动发起付费 AI 请求。
- 原始词表有 388 个词缺音标；已有资料能够补充的会补充，其余显示待补充提示。发音沿用在线英音词典及播放后缓存，不代表所有单词的音频都已离线内置。
- 不下载网站课文、整段词典例句或第三方音频；不加入私人阅读内容。词性/释义和同形异音词仍可能存在来源错误，未宣称全量经过逐词人工审定。

## 学习与升级规则

1. 首页、今日计划、设置和复习来源说明改为“四级词汇”。每天目标 30 个，完成后可继续下一批 30 个。
2. 新概念第一、二册保持原有 20 个目标及跨册衔接，不受四级学习计数影响。
3. 每日复习“四级 / 新概念两册合计”各占一半；不足时补足。今天刚学或仍为 NEW 的词不立即进入复习。
4. Paul1000 与四级交集词原地转换来源，统一大小写拼写，保留 ID、掌握状态、错词次数和所有复习日期。今天已经完成的旧模块数量继续计入今日 30 个目标，不重新要求学习一遍。
5. 非交集的旧词和旧句子卡保留，不再分配为四级新词或常规四级复习；旧错词仍可在错词本查看。新安装不再建立 Paul1000 词卡和句子卡。
6. 四级学习和复习使用同一份单词进度，避免此前单词记录与句子卡记录脱节。重复初始化不会重新创建已转换的 Paul 词。
7. 本次作为 v1.7.3（versionCode 16）更新，无数据库结构变化，不增加权限、服务或用户信息上传。手机需要安装正式签名的更新包才能使用新词库，请覆盖安装，不要卸载旧版。

## 重建与验证

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleRelease
```
